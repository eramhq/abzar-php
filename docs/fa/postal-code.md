# کد پستی

`PostalCode` برای بررسی اولیه شکل کد پستی ایران است.

## نمونه قابل اجرا

کد را کنار `vendor/` ذخیره و اجرا کنید:

```php
<?php
require 'vendor/autoload.php';

use Eram\Abzar\Validation\PostalCode;

$code = PostalCode::from('۱۶۱۹۷۳۵۷۴۴');
echo $code->value(), "\n";
echo $code->zoneCode(), "\n";
```

```text
1619735744
16197
```

## قواعد و نکته‌ها

بعد از تبدیل ارقام و حذف فاصله و خط تیره، دقیقا ده رقم لازم است. رقم اول و پنجم نباید صفر باشند. چهار رقم یکسان پشت سر هم یا بیشتر رد می‌شوند.

`value()` مقدار کامل و `zoneCode()` پنج رقم اول را می‌دهد. نتیجه موفق، `PostalCodeDetails` با فیلدهای `postalCode` و `zoneCode` دارد. `tryFrom()` برای ورودی نامعتبر `null` می‌دهد. `fake()` نمونه با الگوی معتبر می‌سازد و `extractAll()` عددهای ده‌رقمی را بررسی می‌کند.

این validator checksum یا بانک اطلاعات آدرس ندارد. معتبر بودن کد به معنی وجود آدرس یا امکان ارسال مرسوله نیست. عدد ده‌رقمی استخراج‌شده از متن ممکن است کد ملی باشد؛ نوع داده را از زمینه مشخص کنید.

## کدهای خطا

کدهای همین بخش و پیام دقیق کتابخانه در [جدول کدهای خطا](error-codes.md) آمده است. برای شرط‌های برنامه از کد استفاده کنید، نه متن پیام.
