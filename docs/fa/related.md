# پروژه‌های مرتبط

ابزار برای امکانات عمومی فارسی است و تقویم یا adapter آماده فریم‌ورک ندارد. پروژه‌های زیر مستقل هستند و نسخه و پیش‌نیاز جداگانه دارند.

- [`eram/daynum`](https://github.com/eramhq/daynum) در `composer.json` برای امکانات تقویم شمسی پیشنهاد شده است؛ همراه ابزار نصب نمی‌شود.
- [`eramhq/persian-kit`](https://github.com/eramhq/persian-kit) پروژه جداگانه برای اتصال به WordPress است. این مخزن امکانات و سازگاری فعلی آن را تضمین نمی‌کند؛ مستندات خود پروژه را بررسی کنید.
- [persian-tools](https://github.com/persian-tools/persian-tools) منبع بخشی از الگوریتم‌ها، داده‌های دارای مجوز MIT و نمونه‌های تست است. ابزار جایگزین کاملا یکسان آن نیست؛ [تفاوت‌ها](persian-tools-parity.md) را بخوانید.
- [nikapps/iran-validator](https://github.com/nikapps/iran-validator) پروژه دیگری برای اعتبارسنجی در PHP است. نسخه‌ها و امکانات آن را از مستندات همان پروژه بررسی کنید.

برای adapter متعلق به برنامه خودتان، [اتصال به فریم‌ورک](framework-integration.md) و [راهنمای WordPress](recipes/wordpress.md) را ببینید. پیش‌نیازهای خود ابزار در [نصب](installation.md) آمده است.
